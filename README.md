# COCHIN·OS — Espace Internes Radio B

Portail minimaliste (« Papier Radio / Négatoscope ») donnant un accès direct en 1 tap à toutes les applications des internes de **Radiologie B (Ostéo-Articulaire & RI)** de l'Hôpital Cochin :

1. **Planning Internes (`01 // PLANNING`)** — [mrthomaslef.github.io/agenda-internes](https://mrthomaslef.github.io/agenda-internes/)
2. **Annuaire Cochin (`02 // APP DÉDIÉE`)** — Application séparée dans [`./annuaire/`](./annuaire/index.html) (Postes à 5 chiffres `1XXXX` → conversion automatique `01 58 41 XX XX`, DECT, Consoles, Chefs/Seniors Radio B, Services partenaires & Labos)
3. **BiblioOstéo Cochin (`03 // BIBLIOGRAPHIE`)** — [mrthomaslef.github.io/biblioosteo](https://mrthomaslef.github.io/biblioosteo/)
4. **Quiz Cours (`04 // QUIZ COURS`)** — [radio-thomas-ten.vercel.app](https://radio-thomas-ten.vercel.app)
5. **Guide Infiltrations (`05 // GESTES RADIOGUIDÉS`)** — Application dédiée dans [`./infiltrations/`](./infiltrations/index.html) (Manuel complet 213 pages, 75 fiches & chapitres : Rachis, Épaule, Coude/Poignet/Main, Hanche/Bassin, Genou/Cheville/Pied, Biopsies)
6. **Anticoagulants & AAP (`06 // PROTOCOLE RI`)** — Application dédiée dans [`./anticoagulants/`](./anticoagulants/index.html) (Arrêt, adaptation et reprise des anticoagulants et antiagrégants plaquettaires — RFE 2026)
7. **Archives des Internes (`07 // ARCHIVES PDF`)** — Application dédiée dans [`./archives/`](./archives/index.html) (Archives partagées des présentations en PDF, affichées à l'identique : Bone Club, Cas du mardi, Biblio du vendredi & Cours — accès par code)
8. **Quiz Anatomie (`08 // E-ANATOMY`)** — [mrthomaslef.github.io/anatomie-quiz](https://mrthomaslef.github.io/anatomie-quiz/) (Quiz interactif sur 278 planches MSK IMAIOS e-Anatomy : Membre Supérieur, Membre Inférieur, Rachis & Dos)
